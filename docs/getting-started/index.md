# Getting started

Three steps take you from a clean machine to a running agent with persistent memory:

1. [Install](installation.md) the package and, if you want non-Gemini models, the LiteLLM extra.
2. Follow the [Quickstart](quickstart.md): set one API key, ask a few questions, and watch it learn.
3. Tune it with [Configuration](configuration.md): every setting is an environment variable.

!!! tip "No API key yet?"
    `python -m pytest` runs the whole workflow offline, using a scripted model and recorded API
    payloads. It's the quickest way to see every node fire.
