# Worked examples

Each example is **generated by running the real code**:

```bash
python scripts/generate_doc_examples.py
```

The script drives the real ADK 2.x workflow, knowledge graph, compiler, executor, glossary,
learner and ingestion pipeline. Two things are substituted so the output is reproducible and needs
no keys:

| Substituted | With | Why |
|---|---|---|
| The planner, synthesizer and critic | A script that returns a fixed plan, answer and verdict per scenario | Model output varies; the point is to show what the **system** does with it |
| The public APIs | Recorded sample payloads in the live APIs' exact response shapes | Live weather and rates change every minute |

Everything else is computed: dependency closure, composite expansion, parallel levels, glossary
normalisation, step results, failure handling, routing, plan caching, procedure induction,
promotion, lessons, ingestion review and apply. Latencies show as ~0 ms because the APIs are
local; with live APIs you'll see real network times.

!!! info "Run them live"
    Ask the same questions in `python scripts/run_cli.py` with a model key configured. You'll get
    the same plans and levels, with today's data.
